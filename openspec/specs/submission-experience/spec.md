## ADDED Requirements

### Requirement: Immersive Landing and Submission
The system SHALL present a visually appealing, centered layout with plenty of whitespace for the initial complaint submission, making the value proposition obvious.

#### Scenario: User visits submission page
- **WHEN** the user navigates to `/submit`
- **THEN** they see an emotionally engaging centered layout.

### Requirement: Professional AI Processing Animation
The system SHALL replace any generic spinners with a subtle, restrained data-processing animation when submitting a complaint to the AI.

#### Scenario: AI analyzes the complaint
- **WHEN** the user submits the form
- **THEN** the processing state looks like civic data structuring (e.g., pulsing nodes or lists) rather than a sci-fi brain.

### Requirement: Structured Success State
The system SHALL display the AI classification visually distinct and beautifully structured upon successful submission.

#### Scenario: Complaint is classified
- **WHEN** the backend returns the structured data
- **THEN** the UI clearly highlights the determined Category, Priority, and Location using semantic colors.
